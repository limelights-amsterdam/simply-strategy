# Strategy jargon, and what to write instead

<!-- stratlint-ignore-start -->

These words are not wrong because they are ugly. They are wrong because they imitate a decision. Whoever reads them thinks something was chosen, and that is exactly what did not happen.

The replacement is never a synonym. It is the fact, the number, the customer or the action the word stood in for. If you cannot name that, there was no content underneath and cutting is the answer.

## 1. Words that imitate a decision

| Term | What to write instead |
| --- | --- |
| synergies | which two units, and how much it saves in money or hours |
| leverage our core competencies | which skill, and which competitor lacks it |
| strategic alignment | who decides, and what they decided |
| value creation | for whom, measured how |
| holistic approach | which parts, and who owns the whole |
| north star | the number and the date |
| double down on | how much more money, taken from where |
| unlock value | which revenue, from which customer |
| operating model | who reports to whom, and who signs off |
| transformation journey | from what state to what state, by when |
| best-in-class, world-class | the ranking and the source |
| thought leadership | what you will publish, and who reads it |
| paradigm shift | what stops working |
| at scale | at what volume |
| low-hanging fruit, quick wins | the three actions and the return on each |
| table stakes | what you must have to be considered at all |
| boil the ocean | which part you are cutting |
| move the needle | which number, by how much |
| win-win | what each side gives up |
| going forward, moving forward | (drop it) |
| strategic priority | the decision itself |
| customer-centric | what you stopped doing that customers disliked |
| data-driven | which decision now follows which number |
| enable the business | which task you take off their hands |
| drive growth | through which customer, buying what |
| build capabilities | who you hire, or what you buy |
| optimise | from what to what |
| explore opportunities in | when the answer arrives, and who decides |
| right to win | why the customer picks you over the named alternative |
| flywheel | the loop, step by step, with the number that compounds |
| step change | the old number and the new one |
| best practice | who does it, and what happened to their numbers |
| unlock synergies across | the two teams and the shared cost line |
| future-proof | until when, and against which change |
| ecosystem | the names of the parties |
| agile, nimble | what now takes a week that used to take a quarter |
| scale the business | from how many customers to how many, without extra staff |
| align stakeholders | who has to say yes, and what they get for it |
| revisit, reassess | the decision you may reverse |

## 2. False sacrifices

These sentences look like a choice but name nothing concrete. They fail the sacrifice test.

| False sacrifice | What it must become |
| --- | --- |
| We say no to what doesn't fit | We decline deals below 25k |
| We focus more sharply | We stop products B and C |
| We prioritise ruthlessly | These four ship, these seven do not |
| We make hard choices | (which) |
| We do less, but better | Which work stops |
| We rationalise the portfolio | Which product is cut |
| We cut costs | Which line, how much, by when |
| We sharpen our focus | Which market we leave |

## 3. Words that are allowed

Not every technical term is empty. These may stay once they are defined, because they then point at something you can measure or name:

- **Segment** — if you say which segment, with a boundary.
- **Market share** — with a denominator and a reference date.
- **Margin, lead time, retention, acquisition cost** — these are numbers.
- **Moat, right to win** — if you name the reason the competitor does not copy it.
- **Value proposition** — if it states what the customer buys and why from you.
- **Hypothesis** — if a test and a date come with it.
- **Assumption** — in fact you want these stated explicitly in the document.

The underlying rule: a technical term is fine when it is shorter than its definition and the reader knows that definition. If in doubt, write it out once and use the term after that.
