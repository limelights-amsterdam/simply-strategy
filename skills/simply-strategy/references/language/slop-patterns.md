# Replacement lists

Look up a concrete replacement here. These are not a banned-word list. Banning a word barely helps.
Knowing *why* the word is vague, and what goes in its place, does help.

Every word below has the same problem: it sounds like information but points at nothing. The
replacement is almost always the fact, the action or the number the word stood in for.

## 1. Marketing adjectives

These claim quality instead of showing it. The replacement is the fact the claim rests on. If you
cannot name that fact, you did not have a claim.

| Word | What you probably mean |
| --- | --- |
| seamless, frictionless | no extra step needed |
| powerful | say what it does |
| cutting-edge, next-generation, state-of-the-art | say what changed |
| game-changing, revolutionary, disruptive | say what is different now |
| robust, reliable, battle-tested | give the uptime or error rate |
| comprehensive, complete, full-featured | list what is included |
| best-in-class, world-class, industry-leading | give the ranking or the number |
| effortless, simple, easy | give the number of steps |
| scalable | say to what volume |
| blazing fast, lightning fast | give the time in milliseconds |
| intuitive, user-friendly | say what the user no longer has to do |
| smart, intelligent | say what it decides, and on what input |
| delightful, elegant, beautiful | drop it |
| unlock, elevate, supercharge, empower | say the concrete result |
| leverage, harness | use |
| holistic, turnkey, end-to-end | say what it covers |
| bespoke, tailored | say what changes per customer |
| future-proof | drop it |

## 3. Frozen verbs

An empty verb plus a noun with the action hidden inside it. Put the action back in the verb: the
sentence gets shorter and gains an actor.

| Instead of | Write |
| --- | --- |
| perform an analysis of | analyze |
| conduct a review of | review |
| provide assistance to | help |
| make a decision about | decide |
| carry out an inspection | inspect |
| give consideration to | consider |
| take into account | consider |
| make an adjustment to | adjust |
| provide a description of | describe |
| is responsible for the management of | manages |
| has the ability to | can |
| in the event that | if |
| reach a conclusion | conclude |
| undertake an evaluation | evaluate |

## 4. Hedges and stacked qualifiers

One hedge is honest. Four stacked means you do not know and will not say so. Say you do not know.

may · might · could potentially · arguably · generally speaking · in many cases · tends to ·
somewhat · relatively · fairly · more or less · it is important to note that · it should be noted
that · it is worth mentioning that · in a sense · to some extent · one could argue

- ❌ It is important to note that this change could potentially contribute to a better load time.
- ✅ This probably makes the page faster. I have not measured it.

## 5. Filler openings

These say nothing and cost the reader a line. Cut them and start at the content.

In this section, we'll explore… · It's worth noting that… · As mentioned earlier… · In today's
fast-paced world… · There are a number of factors… · Let's dive into… · At the end of the day… ·
Before we begin… · Without further ado…

Also cut: the rhetorical question as a heading ("Why does this matter?"), and the closing summary
that only repeats what was just said.

## 6. Synonym clusters

Pick one word per cluster and keep it for the whole document. Rotating reads like variety, but the
reader wonders whether it is still the same thing.

| Cluster |
| --- |
| user · customer · client · end user · visitor |
| app · application · tool · platform · solution · system |
| issue · problem · bug · defect · error |
| way · approach · method · technique · process |
| start · begin · commence · initiate · kick off |
| remove · delete · erase · clear · take off |
| change · modify · update · adjust · alter |
| show · display · present · render |
| create · build · make · set up · generate |
| check · verify · validate · confirm · review |

Prefer the shortest, most ordinary word in the row.

## 7. Turning passive into active

Passive hides the actor. Sometimes that actor is exactly what the reader needs.

| Passive | Active |
| --- | --- |
| The key is stored in `.env`. | Store the key in `.env`. (instruction) / The script stores the key in `.env`. (description) |
| It was decided to postpone the release. | We are postponing the release. |
| The error was caused by an expired token. | An expired token caused the error. |
| The file is created by the installer. | The installer creates the file. |
| It was determined that the cache was stale. | We found the cache was stale. |

Passive can stay when you genuinely do not know the actor: *The table was deleted somewhere between
March and June.*

Spotting it: `is/are/was/were/been` + a past participle.
